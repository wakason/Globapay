**Fast setup and testing reference for APDS7311 assignment**

## ⚡ Quick Setup (5 Minutes)

### 1. Start Database
```powershell
# Open XAMPP Control Panel
# Start MySQL service
```

### 2. Start Backend
```powershell
cd C:\Users\Administrator\Desktop\GloBaPay\app_backend
npm run dev
```
**Expected**: `HTTPS server running on https://localhost:5000`

### 3. Start Frontend (New Terminal)
```powershell
cd C:\Users\Administrator\Desktop\GloBaPay
npm start
```
**Expected**: Browser opens to `https://localhost:3000`

## 🧪 Quick Test Workflow

### Test Customer Portal (5 minutes)

1. **Login**: Use customer1 / Customer!234
2. **Make Payment**:
   - Amount: `1500.00`
   - Currency: `USD`
   - Recipient Name: `Jane Doe`
   - Recipient Account: `9876543210`
   - SWIFT Code: `DEUTDEFF`
   - Click "Verify SWIFT" → ✅ Green checkmark
   - Click "Send Payment" → ✅ Success

3. **View History**: Check transaction appears with "pending" status

### Test Employee Portal (3 minutes)

1. **Logout** from customer account
2. **Login**: Use ops_agent_1 / Employee!234
3. **Verify Transaction**:
   - See the payment from customer1
   - Click "Verify" button
   - Click "Submit to SWIFT"
   - ✅ Status changes to "verified"

## ❗ Common Issues

### "Cannot connect to database"
```powershell
# Check MySQL is running in XAMPP
# Then restart backend:
cd app_backend
npm run dev
```

### "Port 5000 already in use"
```powershell
# Find and kill process
netstat -ano | findstr :5000
taskkill /PID <PID> /F
```

### "Certificate error"
```powershell
# Regenerate certificates
cd scripts
node generate-certs.js
```

### "Too many login attempts"
```
Wait 15 minutes or restart backend server
```
